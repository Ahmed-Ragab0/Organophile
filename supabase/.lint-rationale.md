# Why `no-import-prefix` is disabled

Edge Functions are deployed as a standalone file bundle. Inline, version-pinned
specifiers (`jsr:@supabase/supabase-js@2`) resolve identically whether or not an
import map is shipped with the bundle, so the deployed function cannot break
because a `deno.json` failed to travel with it. Bare specifiers would add that
failure mode for no benefit at this size.
